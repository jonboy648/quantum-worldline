# 3. Building the machine

*Draft 2, 2026-09-21, for Jon's check. Third person per OUTLINE.md (draft 1 was Jon's first person).
Sources: `docs/specs/2026-03-10-quantum-worldline-design.md`, `CLAUDE.md`, `agents/*.md`. Counts are

---

Here is what Jon built, in March of 2026, before he understood most of what it would do.

He did not build a physics simulation. He built a staff. Fourteen of them. Each one is a written job
description handed to the same AI, so that one model behaves like fourteen different specialists
depending on which description it is holding. One reads the new physics papers every week. One tracks
what the quantum computer companies are actually shipping, as opposed to announcing. One looks for
mathematical bridges between fields that do not talk to each other. One designs experiments for
quantum computers. One runs the same experiment the ordinary way, on an ordinary computer, so that
nobody gets impressed by a quantum result a laptop could have produced. One comes up with ideas to
test. One has the job of saying no to those ideas. One takes whatever survives and asks what it would
mean.

They are arranged like a small research institute. Three departments: reading, calculating, and
theory. Each has a lead who hands work down to the specialists and passes results back up. On top
sits one coordinator, and that is the one Jon talks to. He asks a question in plain language. It
decides which departments need to be involved. A while later an answer comes back with the receipts
attached.

Every result gets written to a file with an ID number. A paper gets a record. An idea gets a record.
A calculation gets a record. The records are the memory. The staff have none.

That is the strangest thing about working this way, and it is the thing that mattered most later.
Each specialist wakes up with no memory of yesterday. Whatever it learned, it wrote into a file, and
the next version of it starts by reading the file. If the file is wrong, the next version is
confidently wrong in exactly the same way. It writes more files that agree with the first one. Soon
there are three files that all agree with each other and with nothing in the outside world. Jon did
not see that as a danger when he built it. He saw a filing system. It is both, and a later chapter is
about the day the difference showed up.

The first rules he gave them were about tidiness. Put your output in this folder. Use this form.
Every idea goes past the one whose job is to say no before Jon hears about it. Never run anything on
a real quantum computer without asking. Sensible rules, and almost all of them about form. The rules
about truth came later, and they came the hard way.

Jon is not a physicist. His part was the question, and reading what came back. He can follow an
argument if it is made carefully. He can tell when two numbers that are supposed to agree do not. He
can tell when someone, human or machine, is more excited than the evidence allows. That turns out to
be most of the job. The machine reads faster than any person and can calculate in an afternoon what
he could not do in a year. Left to itself, it also prefers the interesting answer to the correct
one. It had already shown that in the first conversation.

He named the whole thing Quantum Worldline, for the worm.

Early on, the machine went to work in the corner of physics from the end of the last chapter, and
the first thing it brought back was a number. The number matched a prediction to within two percent.
It looked like the fingerprint he had asked for.

That number is the next chapter. It is also the reason there is a chapter eight.
